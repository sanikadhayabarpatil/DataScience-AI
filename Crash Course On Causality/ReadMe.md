# Understanding Causality Analysis with Ice Cream Sales

## Project Overview
This project explores the relationship between temperature and ice cream sales using causal inference techniques. The analysis applies advanced statistical and econometric methods to distinguish between correlation and causation, offering insights into consumer behavior influenced by environmental factors.

## Methodology
The study employs observational data and constructs a counterfactual framework using the following econometric models:
- **Multivariate Regression**
- **Instrumental Variables (IV) Analysis**
- **Propensity Score Matching**
- **Regression Discontinuity Design (RDD)**
