**Project Overview**

This project, CodeQuest, is a Python-based algorithmic implementation designed for a final exam assignment. The notebook primarily involves working with algorithms and data structures, utilizing Python's built-in capabilities. The main class Alg processes input data and computes results efficiently.

Installation

To set up the environment for this project, install the required dependencies:

pip install numpy matplotlib

How to Run

Clone this repository and navigate to the project folder:

git clone <repository_url>
cd <project_folder>

Open the Jupyter Notebook and run the cells step by step:

jupyter notebook CodeQuest.ipynb

Features

Implements algorithmic solutions using Python.

Uses class-based structure for modularity.

Computes and evaluates results with optimized logic.

File Structure

exam.ipynb – Main notebook containing the implementation and tests.

Alg class – Core algorithmic implementation.
