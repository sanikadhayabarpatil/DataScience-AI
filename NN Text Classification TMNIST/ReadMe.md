# TMNIST Neural Network Classification

## Project Overview
This project explores **Convolutional Neural Networks (CNNs)** for **image classification** using the **TMNIST dataset**. The dataset is preprocessed and split into training, validation, and testing subsets to ensure a robust evaluation of the model’s performance. Advanced optimization techniques and hyperparameter tuning are applied to enhance accuracy.

## Key Features
- **Dataset Preprocessing**: Data is cleaned, normalized, and structured for training.
- **Model Architecture**: Implements CNNs with convolutional, pooling, and dropout layers.
- **Optimization Techniques**: Uses **hyperparameter tuning** for improved performance.
- **Evaluation Metrics**: Includes accuracy, precision, recall, and F1-score.

    ```bash

    ```

## Implementation Details
- **Deep Learning Framework**: TensorFlow & Keras
- **Preprocessing Methods**: Label encoding, one-hot encoding, PCA
- **Model Structure**:
  - Convolutional Layers
  - Pooling Layers
  - Fully Connected Layers
  - Dropout Regularization

## Results
The model achieves high accuracy on the **TMNIST dataset**, demonstrating the effectiveness of CNNs for image classification tasks.
