These projects were developed between **September 2023 and the present**. This repository serves as a **personal record** of my work, allowing for **better accessibility and continuous updates** as I refine my implementations.

## Featured Projects
### 🧠 **Quantum Computing Tutor**
An AI-powered tutor designed to answer questions, summarize quantum computing papers, and provide research recommendations using **FastAPI, Streamlit, OpenAI API, Pinecone, and AWS S3**.

### 📚 **FraudLens: Credit Card Fraud Detection**
Implemented advanced **machine learning models** to detect fraudulent transactions while addressing class imbalance using **SMOTE, Random Forest, and Gradient Boosting**.

### 🔢 **SolveMate: AI-Powered Math Tutor**
A Hugging Face-based chatbot that provides **step-by-step solutions** to mathematical problems, leveraging **transformers and NLP**.

### 🎨 **Text-to-Image Generation (Stable Diffusion)**
A **Stable Diffusion** implementation using **Keras CV** to generate high-quality images from text descriptions.

### 🛒 **Probabilistic Machine Learning for Walmart Sales Prediction**
Applied **Bayesian modeling with PyMC** to forecast sales trends, improving uncertainty estimation and predictive performance.

### 📝 **NLP Hindi Text Processing**
Processed and analyzed Hindi text using **Indic NLP, fastText embeddings, and AI4Bharat's tools** for tokenization and modeling.
